## API și MCP

- Documentație: [rutele API](https://comunicate.top/ro/documentatie-api) · specificație OpenAPI 3.1: https://comunicate.top/openapi.json · index APIs.json: https://comunicate.top/apis.json
- Gratuit, fără cheie și fără cont (numai citire):
  - `GET https://app.comunicate.top/api/v1/public/stats` — câte publicații și câte nișe are rețeaua.
  - `GET https://app.comunicate.top/api/v1/public/niches?locale=ro` — nișele, cu numărul de publicații și autoritatea medie.
  - `GET https://app.comunicate.top/api/v1/public/niches/{slug}?locale=ro` — o nișă, cu publicații de probă: domeniu, DA, PA, termen, preț.
  - `GET https://app.comunicate.top/api/v1/public/statistici-piata` — distribuția autorității, termenele și prețul pe fiecare tip de campanie.
- Nu există rută publică pentru lista întreagă de publicații, și nicio rută publică nu scrie nimic în platformă.
- Server MCP pentru asistenți: https://app.comunicate.top/mcp (OAuth 2.1 cu PKCE, înregistrare dinamică de client). [Ce poate face](https://comunicate.top/ro/mcp).
- Restul API-ului (catalog cu prețuri, articole, comenzi, publicări, campanii, rapoarte, webhook-uri) cere o cheie emisă din cont.
