## APIs

- **Comunicate.top API** — REST API for press-release/advertorial distribution: free keyless public routes (niches, stats, market statistics) plus authenticated partner routes for articles, media, publications, editorial orders, campaigns, catalog, balance, and reports. Also exposes a hosted MCP server and llms.txt. (`https://app.comunicate.top/api/v1`)

> OpenAPI 3.1.0 (27 paths) confirmed at a stable URL. Public routes are keyless read-only; partner routes require apiKey (bk_live_...) or OAuth 2.1 with PKCE and dynamic client registration. Hosted MCP server at https://app.comunicate.top/mcp uses stateless Streamable HTTP transport (API key or OAuth 2.1); a spending safety gate blocks orders/publishing unless enabled by the account owner. llms.txt maintained (last generated 2026-09-08).
